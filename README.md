

# Portafolio Web - Sebastian Gomez L.

Un espacio digital para convertir mi recorrido en el desarrollo de software en una experiencia visual e interactiva.

🔗 **Explora el portafolio:** [sbngl.github.io/Portafolio](https://sbngl.github.io/Portafolio/)

## La idea detrás del proyecto

Más que una página de presentación, este portafolio es un espacio para reunir el trabajo que voy construyendo, mostrar su evolución y facilitar el acceso a cada proyecto.

La propuesta combina una interfaz visual con interacciones que hacen que la navegación sea más dinámica, sin perder claridad ni facilidad de uso.


##  Tecnologías utilizadas

- **HTML5:** estructura y contenido del sitio.
- **CSS3:** diseño y estilos visuales.
- **JavaScript:** interactividad y animaciones.
- **GitHub Pages:** publicación del portafolio.


## Enfoque del diseño

- **Experiencia visual:** una presentación pensada para destacar el contenido.
- **Interactividad:** efectos y animaciones mediante JavaScript.
- **Adaptabilidad:** atención a la visualización en distintos dispositivos.
- **Simplicidad:** una estructura ligera, sin frameworks innecesarios.

## Evolución

Este proyecto seguirá evolucionando a medida que incorpore nuevas ideas, mejoras visuales y funcionalidades.
